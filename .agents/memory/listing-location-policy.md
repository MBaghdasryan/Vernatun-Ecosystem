---
name: Listing location review
description: Resident coordinate entry must not be treated as proof that a listing location is correct.
---

Resident-supplied coordinates remain pending until authorized staff review them. Residents cannot set the review state, and changing coordinates requires a new review. Only a valid coordinate pair with verified status may be exposed to other residents or displayed as a map location. Keep review metadata server-controlled and within the existing marketplace visibility boundary.

**Why:** The user explicitly required confirmed coordinates before map pins so inaccurate resident-entered locations are not presented as verified.

**How to apply:** Preserve this rule in any listing editor, marketplace API, comparison flow, map surface, and staff review workflow.
