# Edge: права и границы

Проверки выполняются на сервере для каждой операции. Видимость кнопки не заменяет разрешение, MFA, свежую авторизацию, активный модуль и организационную/зданийную область.

| Операция | Разрешение | Platform admin | Администратор УК |
|---|---|---|---|
| Общий парк | `edge.fleet.read` + Edge read | Все разрешённые организации | Нет |
| Собственный парк/карточка | `edge.read`, `edge.inventory.read` или `edge.health.read` | Да | Только своя область |
| Устройства/телеметрия | `edge.inventory.read` | Да | Своя область |
| События | `edge.events.read` | Да | Своя область |
| Тревоги | `edge.alarms.read` | Да | Своя область |
| Аудит | `edge.audit.read` | Да | Своя область |
| Создать/редактировать/архивировать узел | `edge.manage` | Да | Своя область |
| Создать bootstrap token | `edge.bootstrap.create` + свежая авторизация | Да | Своя область |
| Отменить неиспользованный bootstrap token | `edge.bootstrap.create` + свежая авторизация | Да | Своя область; не многозданийный блок за пределами назначенного здания |
| Изменить интервалы/модули | `edge.manage` + `edge.config.manage` | Да | Своя область |
| Блоки/здания | Существующие `edge.bootstrap.create` и/или `edge.manage` по операции | Все организации | Своя область |
| Ротация/отзыв credentials | `edge.credentials.rotate/revoke` и глобальная роль `platform_admin` | Да | Нет |
| Назначить устройству помещения | `edge.manage` | Да | Только допустимые здание/организация |

Обычный менеджер, диспетчер, инженер или support не получает управление автоматически. Интерфейс отражает эффективные права существующего IAM; профили/индивидуальные ограничения не обходят базовую роль, модуль и область данных.

Организационный пользователь не может передать чужой `organizationId` в фильтре или мутации. Чужой узел возвращает 404; неподходящая область запроса — 403. Пользователь, ограниченный одним зданием, не получает подробности и управление многозданийной нодой, содержащей чужие для него здания.

Не меняются организация/идентичность существующего узла через общий PATCH. В v1 scope одного здания неизменяем; v2 допускает только явные здания своего блока. Перенос с потерей исторических связей отвергается.

Bootstrap plaintext возвращается один раз; в БД остаётся хэш, а в списках — только метаданные. Ни hash, ни действующие машинные credentials не входят в human detail response. Общий API использует `Cache-Control: no-store`.

`FIRE.CONTROL` и `ELEVATOR.SAFETY_CONTROL` не становятся доступными через конфигурацию. Неподтверждённые физические команды в новой странице отключены. Старый разрешённый resident command flow не расширялся.

Миграция 043 дополняет platform_admin недостающими Edge read/config permissions и снимает машинную ротацию/отзыв с org_admin. Ограничение ротации дополнительно проверяется обработчиком, а не только записью роли.
